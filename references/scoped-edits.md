# 局部编辑与动画

## 决定本次产物

以最新明确指令与用户当前文件为准。纯风格迁移、单页补充和单个公式修改是不同任务，不因之前曾要求精读补充而混在一起。用户撤回内容重构后，停止补充内容。文章梳理规则的更新不授权重做已交付的课件，也不授权在纯风格迁移里重排页序或改写正文。

| 请求 | 执行范围 |
| --- | --- |
| 内容不变，只迁移风格 | 字体、配色、间距、对齐及必要的视觉布局。保留文字、公式含义、图表数据、实际页序和备注 |
| 按这个风格再做一张论文结构 | 一页结构总览，无额外封面。基于真实章节及子节，不改原稿，除非明确要求并入 |
| 让公式像 LaTeX 那样好看 | 调整数学字体、上下标、括号、算符和间距，保留语义。见 [公式](formulas.md) |
| 下面 g/f 换成 h/w | 对应项定点替换，更新其回退图及备注；保留布局、配色、组合和现有动画 |
| 点击一下整图才进来 | 整图一个进入动画，默认一次单击整体进入，不把每个节点拆成多次点击 |
| 把这个推导做成动画 / 要一段三维直觉 | 只加这一段运动。用 [运动讲解](motion.md) 渲染 MP4 并嵌进 PPTX；可编辑式子仍走 OMML，流程仍走原生形状。没有 ManimGX 时不改成整页图片，备注写明动画未渲染 |

## 短流程

1. 找到最新文件并读取相关页。不能只凭 `slide3.xml` 判断“第3页”，需读 `presentation.xml` 及关系表确认实际顺序。截图用于定位和外观参考，不是重建整份文稿的指令。
2. 打开已有 PPTX 时默认另存工作副本，不改原件。用 `scripts/safe_edit.py`：不加 `--in-place` 时复制到新路径，并记录源文件 sha256。只有本次指令明确授权覆盖原文件时才传 `--in-place`。已有脚本若本来就写到另一个输出路径（`inject_omml.py`、`inline_math.py`、`embed_motion.py`、`diagram_helpers.py --output` / `--samples`、`chart_helpers.py --output`），保持该行为，不要改成默默覆盖 `assets/demo.pptx`。文件在编辑器中打开时可用共享读取获取快照，不关闭用户文稿。写回前核对源文件 sha256；有并发修改时另存结果，不覆盖用户新版本。
3. 记录本次允许改变的对象和属性。在工作副本中定点编辑，优先保留原对象、组合、裁切和关系；不借小修重写全稿。不得删除、隐藏、移动或替换调用方没有点名的形状、图片、表格、公式、连接线或组合。
4. 真实渲染受影响页，按原画幅查看公式和文字的基线、字形、间距及溢出。符号替换还需查看回退显示；动画需另外核验时序。
5. 对比基线：未授权的页面内容、备注与数据不变。直接修改 OOXML 时优先确认只改了预期包成员；经 Office 保存时接受序列化差异，但要做语义和显示检查。
6. 输出一个明确的新文件。单页素材交付 PPTX，便于保留可编辑性及动画；不默认同时导出图片、PDF或额外素材包。用户要求合入时才改其指定整稿副本。

局部任务不必重新初始化整稿 `run_state`，也不需要另一次大纲/样张批准。密度、图占比和下半区填充规则不授权扩大范围。

## 保留未点名的对象

助手只能新增或修改本次点名的对象。不得删除、隐藏、移动或替换调用方没有要求改动的形状、图片、表格、公式、连接线或组合。在已有页上调用 `diagram_helpers`、`chart_helpers`（含折线和散点）、`layout_helpers`、`appear`、`inject_omml`、`inline_math`、`embed_motion` 时，页上原有对象的名称、文字、形状标识和位置保持不变。空白页是用户留下的，不要为了通过检查补一个透明形状。

`tests/test_preserve_existing.py` 在临时目录里放入名为 `PREEXISTING_SENTINEL` 的形状，再调用这些助手，确认该形状仍在且标识与文字未变。本机没有 LibreOffice 时跳过渲染，只做 XML / 对象断言。临时目录在测试结束后删除。

## 点击进入动画

PNG/SVG 自身不保存 PowerPoint 单击触发。用户要“图片点击才出现”时，将图片或可编辑重建图放入 PPTX，使用对象进入动画；不能仅设置换页切换或提供静态图片。

- “整图进入”以一个组为动画目标；公式与标签保留编辑性。分步进入只在用户要求时采用。新建页可以用 `scripts/appear.py` 的 `add_click_appear`。整图进入传 `together=True`（一次单击，不把对象打组，因此不必把公式栅格化）。逐条进入才不传 `together`。已有 `p:timing` 时不要覆盖。不调用就没有进入动画。这不是 ManimGX。
- 使用单击触发、进入效果。轻微浮入或淡入可作为默认，约 0.5–0.7 秒；不自行叠加声音、循环或夸张跳动。
- Office 原生公式可能导致 UI/COM 拒绝直接组合。优先保留公式，用支持组合的原生组结构或工具实现；不要为了组合把公式栅格化。手动组结构仍需检查坐标变换、对象 ID 和动画目标。
- PowerPoint 可用时，检查效果为 entrance、trigger 为 on-click、目标是整组；已设置动画和实际观看过放映是两种验证，不混称。
- 继续改公式时保留 timing/动画关系，更新公式兼容回退。导出/重新保存后再次核查动画仍在。
- 新建素材便于复制整页或整个组；不要宣称截图、另存图片或跨软件粘贴一定能保留动画。

## 复核情景

这些情景用于改动规范后的行为复核，不要求每次制作都跑一遍。

| 输入情景 | 应观察到的结果 |
| --- | --- |
| 原稿18页且文字密集，要求内容不变只换风格 | 仍18页，正文和备注内容一致；不因字数上限删减或拆页 |
| 标注“黄色为重要结论”，授权补充精读内容 | 原文结论与证据、条件融入相应页；不自动给幻灯片加黄底 |
| 先要求精读，随后改为仅风格迁移 | 后一范围生效，批注不再触发内容填充 |
| 用户说不用本 skill，只做风格迁移 | 不加载本 skill 制作流程，不强制其脚本和门规则 |
| 按同风格再做一页论文结构 | 一页，不附封面，不擅自修改整稿 |
| 改下方 g/f 为 h/w，已有进入动画 | 对应公式、备注和回退同步；原动画触发、目标及布局保留 |
| 中文句中 tanh、softplus、μ 要数学排版 | 函数名正体、变量数学斜体，中文基线协调，整句便于复制编辑 |
| 用户给出宽条图要求动画 | 图保持比例，PPTX 中一次单击整体进入；静态预览与动画属性分别检查 |
| 用户要求把推导做成动画，本机没有 ManimGX | 公式仍是 OMML，流程仍是原生形状；备注写明动画未渲染。不改成整页图片，也不发明 PNG 导出参数 |
| 原稿有空白页，自动检查报无对象 | 保留用户空白，记录既有问题并做实际核验，不添加透明对象伪造通过 |
| 打开已有 PPTX 小修，没有明确说覆盖原文件 | 源文件字节不变；编辑落在工作副本，并记下源 sha256 |
| 页上已有未点名的形状，再补原生图或条形图 | 原形状的名称、文字、标识和位置仍在；没有 LibreOffice 时不靠渲染下结论 |
