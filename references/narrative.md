# 文章梳理

单篇精读的主线是这篇论文的科学论证。它优先于照搬章节顺序，也优先于把每张图按出现次序走一遍。近期学习汇报仍按阅读事实和收获组织，不必套下面的类型。

视觉、字号和屏幕上放多少，仍按 [风格与版式](style.md) 与 [屏幕密度](density.md)。本页只规定讲什么、按什么顺序讲。叙述上的取舍参考了公开技能里按论文类型组织讲稿的做法，条文是按本仓库的口径重写的。不采用那套屏幕字数预算，也不把正文降到 12–16pt、图注降到 7–9pt。

更新这些规则，不授权重做已经交付的课件。纯风格迁移仍锁定正文、实际页序和备注，不重排内容。见 [局部编辑与动画](scoped-edits.md)。

## 听众要听到的几问

类型弧线没有另行规定时，实质内容按这个顺序：

1. 这个问题为什么重要？
2. 论文针对的缺口或瓶颈是什么？
3. 作者做了什么？
4. 关键证据是什么？
5. 凭什么相信这个结果？看验证、对照和稳健性。
6. 新在哪里，什么可以复用，或有什么更广的意义？
7. 边界和开放问题在哪里？

一份实质汇报里，这几问都要在屏幕上出现过。某一问很短，可以并进相邻页。局限和边界不能只写进备注。

下面某一类写了自己的弧线时，按那条弧线调整顺序和重心。这几问仍要能在屏幕上指出来，不能因为弧线从瓶颈或证据地图写起，就把「为什么重要」或「边界」拿掉。

## 先判定论文类型

从材料判定类型，写进大纲，并按对应弧线给每一页一个角色。类型行只要一句，例如：`论文类型：方法／模型／工具。这是把领域知识写进模型的算法论文。` 向用户说明时也只用这一行。任务是一次做完，或用户说「直接做」：写下类型后继续，不为此停下来问。

弧线和下面的起步角色用来改编，不是把每篇论文塞进同一份页清单，也不是页数上限。对不上的角色删掉，论文另有的关键主张加上。不要为了凑齐清单编造论文没有的机制、基线或临床终点。新稿建议的 8–12 页仍只是起点。论证需要更多页，或同一主题在 18pt 硬底下装不下而拆页时，可以更长。

判不准时：经验性的机制论文用发现／机制；算法、模型、工具论文用方法／模型／工具。

### 发现／机制

弧线是问题到证据：现象 → 缺口 → 问题或假设 → 设计 → 证据链 → 机制或模型 → 边界。

起步角色，按这篇论文删改：

- 现象，以及它为什么重要
- 缺口
- 问题或假设
- 设计
- 证据链（按主张拆页，不按图号）
- 机制或模型
- 边界与开放问题

### 方法／模型／工具／算法

包括人工智能工具，以及领域知情的神经点过程这类模型论文。弧线是问题到方案：瓶颈 → 提出的方法 → 架构或关键设计 → 评价设置 → 相对基线的表现 → 消融、稳健性或失败情形 → 可复用之处与局限。

起步角色，按这篇论文删改：

- 瓶颈
- 提出的方法
- 架构或关键设计
- 评价设置：任务、数据、指标、对照
- 相对基线的表现
- 消融、稳健性或失败情形
- 可复用之处与局限

### 资源／数据集／图谱／基准

弧线是工作流到验证。

起步角色，按这篇论文删改：

- 缺的是什么资源
- 如何构建：采集、标注、划分或规模
- 资源里有什么
- 用什么任务或指标验证它能用
- 相对已有资源新在哪里
- 偏差、许可与使用边界

### 临床／人群／干预

弧线是设计到推断。

起步角色，按这篇论文删改：

- 临床或人群问题
- 设计：对象、干预或暴露、终点、对照
- 主要结果
- 凭什么相信：随机、盲法、随访、混杂
- 能推断什么，不能外推到哪里

### 材料／化学／物理／工程

弧线是性质到机制，或设计到性能。按论文实际的那一条，不要两条都排满。

起步角色，按这篇论文删改：

- 要的性质或性能
- 设计或制备
- 测到的性质或性能
- 机制或结构如何解释
- 相对对照的增益与失效条件
- 边界

### 综述／观点／评论／元分析

弧线是证据地图。

起步角色，按这篇论文删改：

- 在整理什么问题
- 证据如何分块
- 各块上相对一致的结论
- 分歧和证据强弱
- 作者的综合判断
- 仍然开放的问题

封面仍按 [风格与版式](style.md)：论文讲解的第 1 页写题目、作者、会议或期刊与年份。上面的角色不含封面。

## 图是论证的证据

选图和 panel，是因为它们承担主线的下一步。图不是装饰，也不是必须逐张游览的清单。

- 只是重复已经立住的点的图，跳过或合并。
- 支撑主要主张所需要的图，不省。
- 宁可少数看得清的关键 panel，不要一页塞进许多看不清的整图。
- 选中的图要写在屏幕上的事实，在 18pt 硬底下放不下、会溢出或互相遮挡时，把这个主题拆成多页。拆页是为了装下，不是借机把没选上的图再巡一遍。不删关键事实，也不把它们推进备注。
- 不编造数字。正文没有给出、只能从坐标轴估读的数，标「约」。关键数字、对照、各 panel 的读解，以及会改变含义的条件，留在屏幕上。备注写讲解：怎么带着看、过渡和完整出处。用户没有要求自己的收获时，不写个人或实验室的复现。

## 结果页要推进论证

每一页结果都要往前走一步：一条主张、一次对照、一次消融的结果，或一种失败机制。不要只把图贴上，再把图注换个说法读一遍。

标题写成这一页的结论。优先写清主张，例如哪些领域设计有帮助；不要只用图名或章节名，例如「Fig. 6 可见历史」。空的「实验结果」同样不够。标题仍是 32pt，见 [风格与版式](style.md)。

## 不改字号和密度

正文至少 20pt，硬底 18pt。不设每页词数上限。一页放什么，由论文内容和这一页的主题决定。`scripts/audit_pptx.py` 默认不按词数警告，只有传入 `--word-cap` 才检查。本页的角色列表不是页数帽，也不新设词数帽。
