# 文章梳理

单篇精读的主线是这篇论文的科学论证。它优先于照搬章节顺序，也优先于把每张图按出现次序走一遍。近期学习汇报仍按阅读事实和收获组织，不必套下面的类型。

视觉、字号和屏幕上放多少，仍按 [风格与版式](style.md) 与 [屏幕密度](density.md)。本页规定讲什么、按什么顺序讲，以及面向听众用哪一种沟通 mode。论文类型的弧线按本仓库的口径重写，不采用别处的屏幕字数预算，也不把正文降到 12–16pt、图注降到 7–9pt。沟通 mode 同样只吸收「画页面前先把逻辑推敲好」，不改字号和密度。

更新这些规则，不授权重做已经交付的课件。纯风格迁移仍锁定正文、实际页序和备注，不重排内容。见 [局部编辑与动画](scoped-edits.md)。

## 听众要听到的几问

类型弧线没有另行规定时，实质内容按这个顺序：

1. 这个问题为什么重要？
2. 论文针对的缺口或瓶颈是什么？
3. 作者做了什么？
4. 关键证据是什么？
5. 凭什么相信这个结果？看验证、对照和稳健性。
6. 新在哪里，什么可以复用，或有什么更广的意义？
7. 边界和开放问题在哪里？

一份实质汇报里，这几问都要在屏幕上出现过。某一问很短，可以并进相邻页。局限和边界不能只写进备注。

下面某一类写了自己的弧线时，按那条弧线调整顺序和重心。这几问仍要能在屏幕上指出来，不能因为弧线从瓶颈或证据地图写起，就把「为什么重要」或「边界」拿掉。

## 先判定论文类型

从材料判定类型，写进大纲，并按对应弧线给每一页一个角色。类型行只要一句，例如：`论文类型：方法／模型／工具。这是把领域知识写进模型的算法论文。` 向用户说明时也只用这一行。任务是一次做完，或用户说「直接做」：写下论文类型和沟通 mode 后继续，不为此停下来问，也不再为 mode 另问一次。

弧线和下面的起步角色用来改编，不是把每篇论文塞进同一份页清单，也不是页数上限。对不上的角色删掉，论文另有的关键主张加上。不要为了凑齐清单编造论文没有的机制、基线或临床终点。新稿建议的 8–12 页仍只是起点。论证需要更多页，或同一主题在 18pt 硬底下装不下而拆页时，可以更长。

判不准时：经验性的机制论文用发现／机制；算法、模型、工具论文用方法／模型／工具。

### 发现／机制

弧线是问题到证据：现象 → 缺口 → 问题或假设 → 设计 → 证据链 → 机制或模型 → 边界。

起步角色，按这篇论文删改：

- 现象，以及它为什么重要
- 缺口
- 问题或假设
- 设计
- 证据链（按主张拆页，不按图号）
- 机制或模型
- 边界与开放问题

### 方法／模型／工具／算法

包括人工智能工具，以及领域知情的神经点过程这类模型论文。弧线是问题到方案：瓶颈 → 提出的方法 → 架构或关键设计 → 评价设置 → 相对基线的表现 → 消融、稳健性或失败情形 → 可复用之处与局限。

起步角色，按这篇论文删改：

- 瓶颈
- 提出的方法
- 架构或关键设计
- 评价设置：任务、数据、指标、对照
- 相对基线的表现
- 消融、稳健性或失败情形
- 可复用之处与局限

### 资源／数据集／图谱／基准

弧线是工作流到验证。

起步角色，按这篇论文删改：

- 缺的是什么资源
- 如何构建：采集、标注、划分或规模
- 资源里有什么
- 用什么任务或指标验证它能用
- 相对已有资源新在哪里
- 偏差、许可与使用边界

### 临床／人群／干预

弧线是设计到推断。

起步角色，按这篇论文删改：

- 临床或人群问题
- 设计：对象、干预或暴露、终点、对照
- 主要结果
- 凭什么相信：随机、盲法、随访、混杂
- 能推断什么，不能外推到哪里

### 材料／化学／物理／工程

弧线是性质到机制，或设计到性能。按论文实际的那一条，不要两条都排满。

起步角色，按这篇论文删改：

- 要的性质或性能
- 设计或制备
- 测到的性质或性能
- 机制或结构如何解释
- 相对对照的增益与失效条件
- 边界

### 综述／观点／评论／元分析

弧线是证据地图。

起步角色，按这篇论文删改：

- 在整理什么问题
- 证据如何分块
- 各块上相对一致的结论
- 分歧和证据强弱
- 作者的综合判断
- 仍然开放的问题

封面仍按 [风格与版式](style.md)：论文讲解的第 1 页写题目、作者、会议或期刊与年份。上面的角色不含封面。

## 画第一页之前

画第一页之前先写清三件事，再排页。核心信息：听众离开后仍应记住的主张；单篇精读里它就是中心论证，不必另造一句口号。受众结果：听完应该能知道、比较或指出什么。沟通 mode：整份课件只用一个，决定面向这场听众怎么讲。

结构是推敲出来的。可以拆、并、重排、删掉没有页面任务的页、重新框定。不把论文章节、图号或笔记碰巧的顺序原样继承成页序。推敲留住论文里的关键事实和主要主张，不借重排编造论文没有的结论。

## 沟通 mode

mode 是讲法，不是视觉风格，也不是论文类型。英文标签保留，便于和来源对齐。整份只用一个；材料本身是混合的，以正文页的主要讲法为准，不要并列两个 mode。不要为了五种都用过而硬套。对不上就换一个更接近的，或保持默认。

- `pyramid`：结论先行的说服。先让听众听到要接受的判断，再给支撑。标题写成断言。适合明确要求先抛结论、再补证据的场合。结果页仍是主张式标题。局限和边界仍要出现，不能为了说服把它们藏进备注。
- `narrative`：讲故事。沿情境、张力和转折往前走。标题写这一步往前发生了什么。这里的 `narrative` 是讲法标签，不是本文件的文件名。科学事实不能为了故事改写。用户没有要求讲成故事时，不用它做组会精读。
- `instructional`：教学。把内容拆成听得懂的步骤，按先决到依赖、由浅入深来排。并列的概念用同样的形状和深度。标题写这一页在教什么，说清楚优先于说得巧。单篇精读和组会精读默认 `instructional`，除非用户或任务明确要另一种。
- `showcase`：展示。让一张主图、一个大数字或一句短话先被看见。可以有紧有松。它不授权把关键数字、对照和各 panel 的读解挪进备注，也不授权为了留白把字号降到硬底以下。用户没有明确要求展示口吻时，组会精读不用它。
- `briefing`：中性信息通报。把事实铺平，方便查找，不预设立场。标题可以是题目。周报若只是通报读过什么，可以用它。单篇精读不要因此改成资料清单。

### 和论文类型弧一起用

论文类型弧回答这篇论文的科学论证怎么排，发现／机制、方法／模型／工具等弧线仍是单篇精读的主线。沟通 mode 回答面向听众怎么讲。大纲里各写一行，例如 `沟通 mode：instructional。组会精读，按教学顺序讲。` 不要用 mode 替换类型，也不要为了 mode 把类型弧线拆掉。

`instructional` 下面，类型弧线就是教学顺序：先现象或瓶颈，再作者做了什么，再证据，再边界。`pyramid` 只把结论提前让听众先听到，后面的页仍按类型弧线把证据和局限讲完。`briefing` 的题目式标题只用于本来就不是在立主张的通报页；精读的结果页仍写主张。

一次做完，或用户说「直接做」：论文类型和 mode 都记下，然后继续。近期学习汇报可以不填论文类型。它若是在教听众看懂几篇之间的关系，mode 用 `instructional`；若只是通报读过什么，用 `briefing`。

每一页写页面任务（page job）：这一页要让听众完成什么。弧线角色是这一页在论证上的位置；页面任务是听完应能指出或比较的那一件事，例如「听完能指出相对基线好在哪一项」。封面可以很短，例如「认出这篇论文」。没有页面任务的页，并进邻页或删掉。删的是没有任务的页，不是屏幕上的关键事实。

mode 不能冲掉已经写明的规则：论证仍是主线；图仍是证据，不是逐张游览；结果页仍用主张式标题；局限和边界留在屏幕上；字号和密度仍按文末，不因 mode 改小，也不因此设词数帽。

本页只吸收逻辑优先。不采用 SVG 到 DrawingML 的创作管线，也不采用 18 种视觉风格。公式编译器仍是 `scripts/vendor/pptmaster_formula/` 里已经放进来的那一份（ppt-master `4a68cdd`），本次不改这些文件，也不再放进其他模块。原生对象仍是可编辑的 python-pptx 形状、OMML 和可选图表。取舍全文见 [流程来源](provenance.md)。

## 图是论证的证据

选图和 panel，是因为它们承担主线的下一步。图不是装饰，也不是必须逐张游览的清单。

- 只是重复已经立住的点的图，跳过或合并。
- 支撑主要主张所需要的图，不省。
- 宁可少数看得清的关键 panel，不要一页塞进许多看不清的整图。
- 选中的图要写在屏幕上的事实，在 18pt 硬底下放不下、会溢出或互相遮挡时，把这个主题拆成多页。拆页是为了装下，不是借机把没选上的图再巡一遍。不删关键事实，也不把它们推进备注。
- 不编造数字。正文没有给出、只能从坐标轴估读的数，标「约」。关键数字、对照、各 panel 的读解，以及会改变含义的条件，留在屏幕上。备注写讲解：怎么带着看、过渡和完整出处。用户没有要求自己的收获时，不写个人或实验室的复现。

## 结果页要推进论证

每一页结果都要往前走一步：一条主张、一次对照、一次消融的结果，或一种失败机制。不要只把图贴上，再把图注换个说法读一遍。

标题写成这一页的结论。优先写清主张，例如哪些领域设计有帮助；不要只用图名或章节名，例如「Fig. 6 可见历史」。空的「实验结果」同样不够。标题仍是 32pt，见 [风格与版式](style.md)。

## 不改字号和密度

正文至少 20pt，硬底 18pt。不设每页词数上限。一页放什么，由论文内容和这一页的主题决定。`scripts/audit_pptx.py` 默认不按词数警告，只有传入 `--word-cap` 才检查。本页的角色列表不是页数帽，也不新设词数帽。
